\ProjectTitle{Event-Driven Food Delivery Platform (2024 | Group) \hfill \href{https://github.com/FoodDeliveryApp-ISA}{\textbf{Github} \faGithub}}

\noindent
Built a scalable, event-driven food delivery platform using a modern microservices architecture and streaming.

\begin{itemize}
    \item Enabled robust order synchronization using \textbf{Kafka}, processing asynchronous `order\_created` events across distributed microservices.
    \item Integrated \textbf{Redis caching} to improve API performance and reduce PostgreSQL database load, deploying the stack securely via \textbf{Docker}.
\end{itemize}

\noindent
\textit{Keywords:} Java, Spring Boot, Kafka, Redis, PostgreSQL, Docker, Microservices, Event-Driven
