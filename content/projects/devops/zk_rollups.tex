\ProjectTitle{ZK-Rollup L2 Benchmarking Framework}

\noindent
\textit{Research Project — University of Moratuwa}

\begin{itemize}
    \item Built Docker-based benchmark orchestration scripts to evaluate Ethereum Layer-2 trade-offs across sequencing, batching, and data availability.
    \item Implemented the Rust-based Submitter service, observing \textbf{~70\% lower DA publication cost} using EIP-4844-style blobs versus calldata.
    \item Introduced mock-testable clients to improve testability and increased verifiable test coverage from \textbf{41\% to 88\%}.
\end{itemize}

\noindent
\textit{Keywords:} Rust, Docker, Python, L2 Rollups, Benchmarking
