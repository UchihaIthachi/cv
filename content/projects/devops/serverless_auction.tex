\noindent
A capstone project built using AWS, following a microservices architecture with an event-driven, serverless (FaaS) design.

\begin{itemize}
    \item Designed an AWS serverless architecture using \textbf{Lambda}, \textbf{API Gateway}, \textbf{DynamoDB}, \textbf{EventBridge}, \textbf{SQS}, and \textbf{SNS}, with asynchronous event processing and centralized error handling.
    \item Utilized \textbf{LocalStack} and \textbf{Docker} for local cloud emulation, ensuring reliable testing and deployment workflows.
\end{itemize}

\noindent
\textit{Keywords:} Node.js, Serverless Framework, AWS Lambda, DynamoDB, SQS, SNS, EventBridge, LocalStack, Docker
