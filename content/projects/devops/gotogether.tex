\noindent 
Developed and deployed a full-stack travel assistant platform with microservices in Next.js, Spring Boot, and Go. 

\begin{itemize} 
    \item Deployed containerized Next.js, Spring Boot, Go, Keycloak, and PostgreSQL services behind \textbf{NGINX} on \textbf{Oracle Cloud}, with \textbf{Certbot}-managed HTTPS.
    \item Built a dedicated Auth Service using \textbf{Keycloak}, managing OAuth2/OIDC flows, token issuance, and automated realm/client boot-time import scripts.
\end{itemize} 
 
\noindent 
\textit{Keywords:} Next.js, Go, Spring Boot, Keycloak, PostgreSQL, NGINX, Docker, Oracle Cloud, Certbot
