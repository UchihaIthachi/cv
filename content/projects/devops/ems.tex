\noindent
Designed and built a comprehensive, cloud-native microservices application for employee and department management.

\begin{itemize}
    \item Containerized Spring Boot microservices and deployed them using \textbf{Kubernetes manifests} for deployments, services, configuration, and service discovery.
    \item Implemented CI/CD workflows using \textbf{GitHub Actions} and \textbf{ArgoCD}, with centralized configuration, API Gateway routing, Prometheus/Grafana monitoring, and Resilience4j fault tolerance.
\end{itemize}

\noindent
\textit{Keywords:} Spring Boot, Spring Cloud, Kubernetes, Docker, GitHub Actions, ArgoCD, Prometheus, Grafana, Resilience4j, API Gateway
