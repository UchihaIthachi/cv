\nointent 
Developed a full-stack Next.js and Spring Boot platform featuring AI-driven itinerary generation via Gemini API and Keycloak OAuth2. 

\begin{itemize} 
    \item Implemented a \textbf{Spring Boot} social service with \textbf{Keycloak} integration for identity management and a dedicated \textbf{Go} service using \textbf{gRPC} for high-performance inter-service communication. 
    \item Configured production-grade security with \textbf{NGINX, Certbot, and DuckDNS}, and orchestrated deployment on \textbf{Oracle Cloud Free Tier} using custom scripts and Docker optimizations. 
    \item Built a dedicated \textbf{Auth Service using Keycloak}, managing OAuth2/OIDC flows, token issuance, and automated realm/client boot-time import scripts. 
\end{itemize}
