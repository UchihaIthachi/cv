\ProjectTitle{Improving Blockchain Scalability: Throughput Enhancement in ZK-Rollups} 
 
\noindent 
\textit{Research Project — University of Moratuwa} 
 
\begin{itemize} 
    \item Built a modular ZK-rollup framework, developing a Rust Submitter, a mock-testable \texttt{BridgeClient} (increasing test coverage from 41\% to 88\%), and Python data tools to evaluate throughput and latency.
 
    \item Simulated 8 TPS base and 80 TPS burst workloads, demonstrating that EIP-4844-style blob DA reduced publication cost by $\sim$70\% compared to calldata.
\end{itemize} 
 
\noindent 
\textit{Keywords:} Rust, Solidity, Hardhat, TypeScript, Python, Docker, gRPC, SQLite/PostgreSQL, Ethereum Local Test Networks, RISC0, Matplotlib
